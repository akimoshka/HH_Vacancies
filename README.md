# Python Job Vacancies Dashboard

This project is a data visualization dashboard built using scraped job postings from **hh.ru** for Python-related positions in Russia. It provides insights into required experience, salary ranges, employment types, and job title frequency.

## Features

- **Pie Chart** of Employment Types  
- **Treemap** of Job Titles grouped by Employment  
- **Box Plot** of Salary vs Experience  
- **3D Scatter Plot** of Experience, Employment Type, and Salary  
- **Bar Chart** of Top Python Job Titles  

## Files

- `index.html` — the main dashboard homepage  
- `charts/` — contains all interactive and static chart files  
- `python_vacancies.csv` — cleaned dataset with 4500+ vacancies  
- `main.ipynb` — notebook used for scraping data 
-  `visualizations.ipynb` — notebook used for plotting data

## Stack

- Python (Pandas, Seaborn, Plotly)  
- HTML + CSS  
- Deployed with Vercel
